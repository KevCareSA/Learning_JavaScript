# DOCUMENT OBJECT MODEL


## Understanding the DOM

The Document Object Model (DOM) is like a map of your webpage. When you create an HTML page, the browser turns it into the DOM. It's a way for programs (like JavaScript) to understand and change what's on the webpage.

### DOM Structure

The DOM is a tree-like structure where each node is an object representing a part of the document. Nodes can be elements, text, attributes, or comments.

1. **Document Node**: The root node of the document tree.
2. **Element Nodes**: Represent HTML tags and can contain attributes and other nodes.
3. **Attribute Nodes**: Represent HTML attributes and are part of element nodes.
4. **Text Nodes**: Represent the text inside an element or attribute.

### Example HTML and DOM Representation

HTML:

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Document</title>
</head>
<body>
  <h1 id="header">Hello, World!</h1>
  <p class="content">This is a paragraph.</p>
</body>
</html>

```

DOM Tree:

```
Document
├── html
│   ├── head
│   │   └── title
│   └── body
│       ├── h1#header
│       └── p.content

```

## Navigating the DOM

## 1. Accessing Nodes

Accessing nodes in the Document Object Model (DOM) means retrieving references to the elements or components of an HTML document so you can read, manipulate, or modify them. The DOM represents the structure of a document as a tree of nodes, where each node corresponds to a part of the document, such as an element, attribute, or text.

In the context of the web, accessing nodes is crucial for dynamically interacting with the content and structure of a webpage. It allows developers to create, remove, or change elements, respond to user interactions, and update the document in real time.

For example:

- **Reading Content**: You can read the text content or attributes of an element.
- **Manipulating Structure**: You can add new elements, remove existing ones, or reorder elements.
- **Styling**: You can change the style properties of elements.
- **Event Handling**: You can attach event listeners to elements to respond to user actions.
    
    
    Here are the key methods and properties to access nodes:
    
    - **`document.documentElement`**: Accesses the root `<html>` element of the document.
    - **`document.body`**: Accesses the `<body>` element, which contains the visible content of the document.
    - **`document.head`**: Accesses the `<head>` element, which contains metadata and links to resources.
    
    - **`document.documentElement`**: This property provides access to the root element of the HTML document, which is the `<html>` tag. It is the highest-level element in the DOM tree and serves as the parent for both the `<head>` and `<body>` elements. You can use `document.documentElement` to manipulate or retrieve information about the entire document structure.
        
        ```jsx
        console.log(document.documentElement); // Outputs: <html>...</html>
        
        ```
        
    - **`document.body`**: This property gives you access to the `<body>` element of the document, which contains all the content that is visible to the user, such as text, images, and other elements. It's commonly used to append new elements, manipulate existing content, or retrieve information about the visible part of the document.
        
        ```jsx
        console.log(document.body); // Outputs: <body>...</body>
        
        ```
        
    - **`document.head`**: This property provides access to the `<head>` element of the document, which contains metadata about the document, including links to stylesheets, scripts, and other resources. It is typically used to dynamically insert or manipulate these resources.
    
    ```jsx
    console.log(document.head); // Outputs: <head>...</head>
    
    ```
    

## 2. Traversing Nodes

Traversing nodes refers to navigating through the DOM tree to access different elements based on their relationships. This is essential for manipulating or querying specific parts of the document. 

Here are the key properties for traversing nodes:

- **Parent Node**: `node.parentNode`
- **Child Nodes**: `node.childNodes` (returns a NodeList)
- **First Child**: `node.firstChild`
- **Last Child**: `node.lastChild`
- **Next Sibling**: `node.nextSibling`
- **Previous Sibling**: `node.previousSibling`

Example:

- **Parent Node**: `node.parentNode`
    - This property returns the parent node of the specified node. It allows you to move up one level in the DOM tree. If the node is the root node (`<html>`), `parentNode` will return `null`.
    
    ```jsx
    let parent = element.parentNode;
    console.log(parent); // Outputs the parent node of the specified element
    
    ```
    
- **Child Nodes**: `node.childNodes` (returns a NodeList)
    - This property returns a live NodeList of all child nodes of the specified node, including elements, text nodes, and comments. It's useful for iterating over all children of an element.
    
    ```jsx
    let children = element.childNodes;
    children.forEach(child => console.log(child)); // Outputs all child nodes of the specified element
    
    ```
    
- **First Child**: `node.firstChild`
    - This property returns the first child node of the specified node. It's a shortcut to access the first element, text node, or comment within the parent node.
    
    ```jsx
    let firstChild = element.firstChild;
    console.log(firstChild); // Outputs the first child node of the specified element
    
    ```
    
- **Last Child**: `node.lastChild`
    - This property returns the last child node of the specified node. Similar to `firstChild`, it's a shortcut to access the last element, text node, or comment within the parent node.
    
    ```jsx
    let lastChild = element.lastChild;
    console.log(lastChild); // Outputs the last child node of the specified element
    
    ```
    
- **Next Sibling**: `node.nextSibling`
    - This property returns the next sibling of the specified node. It's useful for navigating to the next node at the same level in the DOM tree.
    
    ```jsx
    let nextSibling = element.nextSibling;
    console.log(nextSibling); // Outputs the next sibling of the specified element
    
    ```
    
- **Previous Sibling**: `node.previousSibling`
    - This property returns the previous sibling of the specified node. It's useful for navigating to the previous node at the same level in the DOM tree.
    
    ```jsx
    let previousSibling = element.previousSibling;
    console.log(previousSibling); // Outputs the previous sibling of the specified element
    
    ```
    

These properties are foundational for DOM traversal, allowing you to move through the document structure in various ways to access and manipulate nodes as needed.

### Example

Consider the following DOM structure:

```html
<div id="parent">
  <p id="child1">First Paragraph</p>
  <p id="child2">Second Paragraph</p>
</div>

```

```jsx
var parent = document.getElementById('parent');
var firstChild = parent.firstChild; // First child node (could be a text node)
var firstElementChild = parent.firstElementChild; // First child element
var nextSibling = firstElementChild.nextSibling; // Next sibling node
var nextElementSibling = firstElementChild.nextElementSibling; // Next sibling element

```

## 3. Manipulating the DOM

Manipulating the DOM means changing the structure, style, and content of a webpage using JavaScript. This allows you to update the webpage in real-time, making it interactive and responsive. Here are some detailed explanations and examples for manipulating the DOM:

### Adding Elements

Adding elements to the DOM involves creating new elements and inserting them into the existing document structure.

### Creating a New Element

To create a new element, use `document.createElement(tagName)`. This method creates an element with the specified tag name, but it doesn't add it to the webpage yet.

```jsx
let newDiv = document.createElement('div'); // Creates a new <div> element

```

### Adding a New Child

To actually add the new element to the webpage, use `node.appendChild(childNode)`. This method adds the new element as a child to a specified parent element.

```jsx
document.body.appendChild(newDiv); // Adds the new <div> to the end of the <body>

```

Example:

```jsx
// Create a new paragraph element
let newParagraph = document.createElement('p');
// Set the text content of the new paragraph
newParagraph.textContent = 'This is a new paragraph!';
// Add the new paragraph to the body of the document
document.body.appendChild(newParagraph);

```

### Inserting an Element Before Another

To insert a new element before another specified element, use `node.insertBefore(newNode, referenceNode)`. This method inserts the new element as a sibling to the reference element, placing it before the reference element.

```jsx
let referenceNode = document.getElementById('someElement'); // Find the reference element
document.body.insertBefore(newDiv, referenceNode); // Insert the new <div> before the reference element

```

Example:

```jsx
// Create a new heading element
let newHeading = document.createElement('h1');
// Set the text content of the new heading
newHeading.textContent = 'Welcome!';
// Find an existing element to insert the new heading before
let existingElement = document.getElementById('intro');
// Insert the new heading before the existing element
document.body.insertBefore(newHeading, existingElement);

```

### Removing Elements

Removing elements from the DOM involves deleting existing elements.

### Removing a Child Element

To remove an existing element from the webpage, use `node.removeChild(childNode)`. This method removes the specified child element from its parent element.

```jsx
let childToRemove = document.getElementById('childElement'); // Find the element to remove
document.body.removeChild(childToRemove); // Remove the specified element from the body

```

Example:

```jsx
// Find the paragraph element to remove
let paragraphToRemove = document.getElementById('oldParagraph');
// Remove the paragraph from its parent element
paragraphToRemove.parentNode.removeChild(paragraphToRemove);

```

### Removing an Element Directly

Use the `node.remove()` method to remove an element directly from the DOM.

```jsx
newDiv.remove(); // Removes the new <div> from the DOM

```

Example:

```jsx
// Find the heading element to remove
let headingToRemove = document.getElementById('oldHeading');
// Remove the heading from the DOM
headingToRemove.remove();

```

### Replacing Elements

Replacing elements in the DOM involves swapping an existing element with a new one.

### Replacing a Child Element

To replace an existing element with a new one, use `node.replaceChild(newChild, oldChild)`. This method replaces the old child element with the new child element in the parent node.

```jsx
let newElement = document.createElement('span'); // Create a new <span> element
let oldElement = document.getElementById('oldElement'); // Find the element to be replaced
document.body.replaceChild(newElement, oldElement); // Replace the old element with the new one

```

Example:

```jsx
// Create a new image element
let newImage = document.createElement('img');
// Set the source of the new image
newImage.src = 'new-image.jpg';
// Find the old image element to replace
let oldImage = document.getElementById('oldImage');
// Replace the old image with the new one
document.body.replaceChild(newImage, oldImage);

```

### Changing Content

Changing the content of elements allows you to update what is displayed on the webpage.

### Changing HTML Content

Use `element.innerHTML` to get or set the HTML content inside an element. This property allows you to add or modify HTML content within an element.

```jsx
newDiv.innerHTML = '<p>This is new content</p>'; // Sets new HTML content inside the <div>

```

Example:

```jsx
// Find the div element to change
let divToChange = document.getElementById('content');
// Set new HTML content inside the div
divToChange.innerHTML = '<h2>Updated Content</h2><p>This is the updated content of the div.</p>';

```

### Changing Text Content

Use `element.textContent` to get or set the text content inside an element. This property allows you to add or modify plain text within an element.

```jsx
newDiv.textContent = 'This is new text content'; // Sets new text content inside the <div>

```

Example:

```jsx
// Find the paragraph element to change
let paragraphToChange = document.getElementById('message');
// Set new text content inside the paragraph
paragraphToChange.textContent = 'This is the updated message.';

```

### Changing Attributes

Changing attributes allows you to update the properties of elements, such as their class, id, or custom attributes.

### Setting an Attribute

Use `element.setAttribute(attributeName, value)` to set the value of an attribute on the specified element.

```jsx
newDiv.setAttribute('class', 'myClass'); // Sets the class attribute of the <div> to 'myClass'

```

Example:

```jsx
// Find the link element to change
let linkToChange = document.getElementById('myLink');
// Set the href attribute of the link
linkToChange.setAttribute('href', '<https://www.example.com>');

```

### Getting an Attribute

Use `element.getAttribute(attributeName)` to get the value of an attribute on the specified element.

```jsx
let classValue = newDiv.getAttribute('class'); // Gets the value of the class attribute

```

Example:

```jsx
// Find the image element to get the attribute value from
let imageElement = document.getElementById('myImage');
// Get the value of the src attribute
let imageSource = imageElement.getAttribute('src');
console.log(imageSource); // Outputs the value of the src attribute

```

### Removing an Attribute

Use `element.removeAttribute(attributeName)` to remove an attribute from the specified element.

```jsx
newDiv.removeAttribute('class'); // Removes the class attribute from the <div>

```

Example:

```jsx
// Find the button element to change
let buttonToChange = document.getElementById('submitButton');
// Remove the disabled attribute from the button
buttonToChange.removeAttribute('disabled');

```

### Changing Styles

Changing the style of elements allows you to update their appearance.

### Changing Inline Style

Use `element.style.propertyName` to set or get the inline style property of an element.

```jsx
newDiv.style.color = 'blue'; // Sets the text color of the <div> to blue

```

Example:

```jsx
// Find the header element to style
let headerToStyle = document.getElementById('mainHeader');
// Set the background color of the header
headerToStyle.style.backgroundColor = 'lightblue';

```

By understanding and using these methods, you can dynamically manipulate the content, structure, and appearance of your webpage, making it more interactive and responsive to user actions.

## Manipulating Attributes

### Setting Attributes

- **`setAttribute(name, value)`**: Sets the value of an attribute.
- **`element.id = 'newId'`**: Sets the ID of an element.
- **`element.className = 'newClass'`**: Sets the class name of an element.

```jsx
var element = document.getElementById('header');
element.setAttribute('data-custom', 'customValue');
element.id = 'newHeader';
element.className = 'newClass';

```

### Getting Attributes

- **`getAttribute(name)`**: Gets the value of an attribute.
- **`element.id`**: Gets the ID of an element.
- **`element.className`**: Gets the class name of an element.

```jsx
var element = document.getElementById('header');
var customAttribute = element.getAttribute('data-custom');
var elementId = element.id;
var elementClass = element.className;

```

### Removing Attributes

- **`removeAttribute(name)`**: Removes an attribute.

```jsx
var element = document.getElementById('header');
element.removeAttribute('data-custom');

```

## Manipulating Styles

### Inline Styles

- **`element.style.property = value`**: Sets the inline style of an element.

```jsx
var element = document.getElementById('header');
element.style.color = 'blue';
element.style.fontSize = '20px';

```

### CSS Classes

- **`element.classList.add(className)`**: Adds a class to the element.
- **`element.classList.remove(className)`**: Removes a class from the element.
- **`element.classList.toggle(className)`**: Toggles a class on the element.
- **`element.classList.contains(className)`**: Checks if the element has the class.

```jsx
var element = document.getElementById('header');
element.classList.add('highlight');
element.classList.remove('highlight');
element.classList.toggle('highlight');
var hasClass = element.classList.contains('highlight');

```

## Event Handling

### Adding Event Listeners

- **`addEventListener(event, function)`**: Adds an event listener to the element.

```jsx
var button = document.getElementById('myButton');
button.addEventListener('click', function() {
  alert('Button clicked!');
});

```

### Removing Event Listeners

- **`removeEventListener(event, function)`**: Removes an event listener from the element.

```jsx
var button = document.getElementById('myButton');
function handleClick() {
  alert('Button clicked!');
}
button.addEventListener('click', handleClick);
button.removeEventListener('click', handleClick);

```

1. What is the DOM?

1. Why is the DOM important?

The DOM allows you to:

- Change text on the page
- Add or remove elements (like paragraphs or buttons)
- Respond to user actions (like clicking a button)
- Change how things look on the page
1. Basic DOM Concepts

a) Elements: These are the building blocks of a webpage. For example, paragraphs, headings, buttons, and images are all elements.

b) Attributes: These are additional information about elements. For example, an image has a "src" attribute that tells the browser where to find the image file.

c) Text content: This is the actual text inside an element.

1. Finding Elements

Before you can change something on the page, you need to find it. There are several ways to do this:

a) By ID: If an element has an ID (like <p id="intro">), you can find it using that ID. This is like finding a house by its unique address.

b) By Class: If several elements share a class (like <p class="highlight">), you can find all of them at once. This is like finding all houses painted blue.

c) By Tag Name: You can find all elements of a certain type, like all paragraphs or all buttons.

1. Changing Elements

Once you've found an element, you can change it:

a) Changing text: You can change what a paragraph or heading says.

b) Changing attributes: You can change things like the source of an image or the destination of a link.

c) Changing styles: You can change how an element looks, like its color or size.

1. Creating and Removing Elements

You can also add new things to the page or remove existing things:

a) Creating: You can make a new paragraph, button, or any other element and add it to the page.

b) Removing: You can take away elements you don't want anymore.

1. Responding to Events

An event is something that happens on the page, like:

- Clicking a button
- Moving the mouse
- Typing on the keyboard

You can tell the browser to do something when these events happen.

1. Practical Example (explained, not coded)

Let's say you want to make a simple to-do list:

1. You'd start with a text box where people can type new tasks.
2. You'd have a button to add the task to the list.
3. When someone clicks the button:
    - You'd create a new list item
    - You'd put the text from the text box into this new item
    - You'd add this new item to the list on the page
    - You'd clear the text box so it's ready for the next task
4. For each item, you might add a "delete" button
5. When someone clicks "delete":
    - You'd find the list item that contains this button
    - You'd remove that entire item from the list

This example uses many of the concepts we've discussed: finding elements (the text box and list), creating new elements (new list items), changing elements (clearing the text box), and responding to events (clicks on the "add" and "delete" buttons).
