# 2. FUNCTION EXPRESSIONS

## 1. Function Expressions in JavaScript

Function expressions allow functions to be defined within expressions, giving flexibility in how and where functions are used. Unlike function declarations, function expressions are not hoisted, which means they cannot be called before they are defined.

### Syntax of Function Expressions

```jsx
let functionName = function(parameter1, parameter2, ...parameterN) {
    // Function body
    return returnValue; // Optional return statement
};

```

### Step-by-Step Breakdown

1. **Variable Declaration**:
    - `let functionName`: The function expression is assigned to a variable. You can also use `const` if you don't plan to reassign the function.
2. **Function Keyword**:
    - `function`: This keyword is used to define the function.
3. **Parameters**:
    - `(parameter1, parameter2, ...parameterN)`: These are placeholders for the values that will be passed to the function. They are optional.
4. **Function Body**:
    - `{ ... }`: The block of code inside the curly braces defines what the function does.
5. **Return Statement**:
    - `return returnValue;`: This statement specifies the value to be returned by the function. It is optional. If omitted, the function returns `undefined`.

### Examples of Function Expressions

### Example 1: Basic Function Expression

```jsx
// Function expression to add two numbers
let add = function(a, b) {
    return a + b;
};

// Calling the function
let sum = add(3, 4);
console.log(sum); // Output: 7

```

### Example 2: Anonymous Function Expression

```jsx
// Assigning an anonymous function to a variable
let greet = function() {
    console.log("Hello, world!");
};

// Calling the function
greet(); // Output: Hello, world!

```

### Example 3: Named Function Expression

A named function expression is a function expression with a name. This name is local to the function's scope and can be used for recursion or within the function itself.

```jsx
// Named function expression to calculate the factorial of a number
let factorial = function fact(n) {
    if (n <= 1) {
        return 1;
    } else {
        return n * fact(n - 1); // Using the local name 'fact' for recursion
    }
};

// Calling the function
console.log(factorial(5)); // Output: 120

```

### Advantages of Function Expressions

1. **Flexibility**: Function expressions can be used as arguments to other functions, returned from functions, or assigned to variables dynamically.
2. **Encapsulation**: Named function expressions can encapsulate recursive functions, making them more self-contained.
3. **No Hoisting**: Function expressions are not hoisted, which can lead to more predictable code behavior.

### Use Cases of Function Expressions

### Example 1: Passing a Function Expression as an Argument

```jsx
// Higher-order function that accepts another function as an argument
function repeat(operation, num) {
    for (let i = 0; i < num; i++) {
        operation(); // Call the passed-in function
    }
}

// Using an anonymous function expression as an argument
repeat(function() {
    console.log("Hello!");
}, 3);

// Output:
// Hello!
// Hello!
// Hello!

```

### Example 2: Returning a Function Expression from Another Function

```jsx
// Function that returns another function
function createMultiplier(multiplier) {
    return function(x) {
        return x * multiplier;
    };
}

// Using the returned function
let double = createMultiplier(2);
console.log(double(5)); // Output: 10

let triple = createMultiplier(3);
console.log(triple(5)); // Output: 15

```

### Example 3: Assigning a Function Expression to an Object Property

```jsx
// Creating an object with a method defined as a function expression
let person = {
    name: "Alice",
    greet: function() {
        console.log("Hello, " + this.name + "!");
    }
};

// Calling the method
person.greet(); // Output: Hello, Alice!

```

### Summary

Function expressions in JavaScript are powerful tools that allow you to define functions within expressions and assign them to variables, pass them as arguments, return them from other functions, and more. They provide flexibility and encapsulation, making your code more modular and reusable.
