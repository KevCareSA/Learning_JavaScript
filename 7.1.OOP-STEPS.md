# STEP BY STEP 


## Here's a step-by-step guide on how to build a class in JavaScript:

1. Define the class (blueprint):
    
    ```jsx
    class MyClass {
    }
    
    ```
    
2. Add the constructor:
    
    ```jsx
    class MyClass {
      constructor() {
      }
    }
    
    ```
    
3. Add properties in the constructor:
    
    ```jsx
    class MyClass {
      constructor(param1, param2) {
        this.property1 = param1;
        this.property2 = param2;
      }
    }
    
    ```
    
4. Add methods:
    
    ```jsx
    class MyClass {
      constructor(param1, param2) {
        this.property1 = param1;
        this.property2 = param2;
      }
    
      method1() {
        // Method logic here
      }
    
      method2() {
        // Method logic here
      }
    }
    
    ```
    
5. (Optional) Add static properties or methods:
    
    ```jsx
    class MyClass {
      static staticProperty = "I'm static";
    
      static staticMethod() {
        // Static method logic
      }
    
      constructor(param1, param2) {
        this.property1 = param1;
        this.property2 = param2;
      }
    
      method1() {
        // Method logic here
      }
    
      method2() {
        // Method logic here
      }
    }
    
    ```
    
6. Use the class:
    
    ```jsx
    const myObject = new MyClass("value1", "value2");
    myObject.method1();
    MyClass.staticMethod();
    
    ```
