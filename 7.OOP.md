# OBJECT ORIENTED PROGRAMMING (OOP)


## What is an Object?

In JavaScript, an object is a way to store multiple pieces of data as a single entity. Objects can hold both properties (data) and methods (functions). Think of an object as a box that can hold different items, and each item has a label (key) and a value.

### Basic Structure of an Object

1. **Properties:** These are the values associated with the object. They are written as key-value pairs.
2. **Methods:** These are functions stored as properties. They define actions that can be performed on the object.

### Syntax

The basic syntax for defining an object is:

```jsx
let objectName = {
  key1: value1,
  key2: value2,
  method1: function() {
    // code for method
  }
};

```

### Real-World Analogy: A Book

Let's use the analogy of a book to explain objects:

- **Properties:** Characteristics of the book (title, author, pages).
- **Methods:** Actions you can perform on the book (read, bookmark).

### Example: Book Object

Let's create an object representing a book:

```jsx
let book = {
  title: "The Great Gatsby",
  author: "F. Scott Fitzgerald",
  pages: 180,

  read: function() {
    console.log("Reading the book...");
  },

  bookmark: function(page) {
    console.log("Bookmarked page " + page);
  }
};

```

### Breaking Down the Example

1. **Object Name:** `book`
2. **Properties:**
    - `title` with value `"The Great Gatsby"`
    - `author` with value `"F. Scott Fitzgerald"`
    - `pages` with value `180`
3. **Methods:**
    - `read` which logs `"Reading the book..."` when called
    - `bookmark` which takes a `page` parameter and logs the bookmarked page

### Accessing Properties and Methods

You can access the properties and methods using dot notation or bracket notation.

**Dot Notation:**

```jsx
console.log(book.title);       // Output: The Great Gatsby
book.read();                   // Output: Reading the book...
book.bookmark(50);             // Output: Bookmarked page 50

```

**Bracket Notation:**

```jsx
console.log(book["author"]);   // Output: F. Scott Fitzgerald
book["read"]();                // Output: Reading the book...
book ;         // Output: Bookmarked page 100

```

### Adding and Modifying Properties

You can add new properties or modify existing ones:

```jsx
book.genre = "Fiction";        // Adding a new property
book.pages = 200;              // Modifying an existing property

console.log(book.genre);       // Output: Fiction
console.log(book.pages);       // Output: 200

```

### Removing Properties

You can remove properties using the `delete` keyword:

```jsx
delete book.pages;

console.log(book.pages);       // Output: undefined

```

### Full Example

Here's the complete example:

```jsx
let book = {
  title: "The Great Gatsby",
  author: "F. Scott Fitzgerald",
  pages: 180,

  read: function() {
    console.log("Reading the book...");
  },

  bookmark: function(page) {
    console.log("Bookmarked page " + page);
  }
};

// Accessing properties
console.log(book.title);       // Output: The Great Gatsby
console.log(book["author"]);   // Output: F. Scott Fitzgerald

// Calling methods
book.read();                   // Output: Reading the book...
book.bookmark(50);             // Output: Bookmarked page 50

// Adding and modifying properties
book.genre = "Fiction";
book.pages = 200;

console.log(book.genre);       // Output: Fiction
console.log(book.pages);       // Output: 200

// Removing properties
delete book.pages;
console.log(book.pages);       // Output: undefined

```

### Summary

- **Object:** A collection of properties and methods.
- **Properties:** Key-value pairs that store data.
- **Methods:** Functions that define actions on the object.
- **Accessing:** Use dot notation or bracket notation.
- **Modifying:** Add, update, or delete properties as needed.

## What is OOP in JavaScript?

**Object-Oriented Programming (OOP)** in JavaScript is a programming paradigm that uses objects and classes to structure and organize code. The key concepts of OOP include:

1. **Encapsulation:** Bundling data (properties) and functions (methods) that operate on the data into a single unit called a class. This helps in hiding the internal state of the object and only exposing a controlled interface.
2. **Abstraction:** Hiding the complex implementation details and exposing only the necessary parts of an object. This makes it easier to interact with objects without needing to understand their internal workings.
3. **Inheritance:** A mechanism where a new class (child class) derives properties and methods from an existing class (parent class). This promotes code reuse and the creation of a class hierarchy.
4. **Polymorphism:** The ability to use a single interface to represent different underlying data types. This allows objects to be treated as instances of their parent class rather than their actual class, enabling method overriding and the use of the same method names for different behaviors.

### What is a Class?

A **class** is a blueprint for creating objects. It defines a set of properties and methods that the objects created from the class will have.

**Syntax and Structure:**

- **Class Declaration:** Use the `class` keyword followed by the class name.
- **Constructor Method:** A special method for initializing new objects. It sets up the initial state of an object by assigning values to properties.
- **Methods:** Functions defined within a class that describe the behaviors of the objects created from the class.

**Structure Explanation:**

1. **Class Declaration:** The starting point of a class definition. It names the class and contains the body where properties and methods are defined.
2. **Constructor Method:** Initializes the object's properties when a new instance is created. This method typically takes parameters to set initial values for the properties.
3. **Methods:** Define the actions that an object can perform. Methods are defined inside the class body and can operate on the object's properties.

CLASS EXAMPLE:

A **class** is a blueprint for creating objects. It defines properties and methods that the objects created from the class will have.

**Syntax:**

```jsx
class ClassName {
  constructor(parameters) {
    // Initialize properties
    this.property1 = value1;
    this.property2 = value2;
  }

  method1() {
    // Method logic
  }

  method2() {
    // Method logic
  }
}

```

**Breakdown:**

- `class ClassName { ... }`: Declares a class named `ClassName`.
- `constructor(parameters) { ... }`: A special method for initializing new objects. It sets up the initial state of an object by assigning values to properties.
- `this.property1 = value1;`: Sets the value of `property1` for the object being created.
- `method1() { ... }`: Defines a method named `method1` that describes an action the object can perform.

### What are Objects?

An **object** is an instance of a class. It is created using the class blueprint and represents a specific entity with properties and methods defined by the class.

**Syntax and Structure:**

- **Object Creation:** Use the `new` keyword followed by the class name and any necessary arguments for the constructor method.
- **Accessing Properties and Methods:** Use dot notation to access an object's properties and call its methods.

**Structure Explanation:**

1. **Object Creation:** Involves creating a specific instance of a class using the `new` keyword. This process initializes the object's properties based on the constructor method of the class.
2. **Accessing Properties and Methods:** Once an object is created, its properties and methods can be accessed using dot notation. This allows interaction with the object's data and behaviors.

An **object** is an instance of a class. It is created using the class blueprint and represents a specific entity with properties and methods defined by the class.

### What are Properties and Methods?

**Properties** and **methods** are the fundamental components of objects in OOP.

**Properties:**

- **Attributes:** These are variables that belong to an object. They hold data specific to the object.
- **Initialization:** Properties are typically initialized in the constructor method when an object is created.

**Methods:**

- **Functions:** These are functions that belong to an object. They define the actions or behaviors the object can perform.
- **Definition:** Methods are defined inside the class body and can use and modify the object's properties.

**Structure Explanation:**

1. **Properties (Attributes):** Defined within the class, typically initialized in the constructor method. They store data related to the object.
2. **Methods (Functions):** Defined within the class and describe what an object can do. They can manipulate the object's properties and perform various operations.

**Properties** are variables that belong to an object. They hold data specific to the object.

**Methods** are functions that belong to an object. They define the actions or behaviors the object can perform.

- `stop() { ... }`: Defines a `stop` method that logs a message indicating the car has stopped.
